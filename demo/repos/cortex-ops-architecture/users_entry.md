# Users & entry points

This page maps users to the workbenches, agent domains, and views they actually use. It intentionally avoids the low-value "all users go to the browser" view.

## Role Groups

- Field users: CRA + Study Monitor
- Ops leaders: Study Manager + Regional Manager + Portfolio Head
- Data/regulatory users: Data Lead + CRO Lead
- AI/platform users: AI Lead

## Workbenches

- Field execution: site visits, nudges, follow-up
- Study command: KRIs, resource allocation, HITL review
- Data quality: queries, DB lock, ontology/coding
- AI governance: prompt audit, connector health, identity/security
