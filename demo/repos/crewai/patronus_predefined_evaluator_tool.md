# patronus_predefined_evaluator_tool

## Introduction
The `patronus_predefined_evaluator_tool` module provides the `PatronusPredefinedCriteriaEvalTool`, a specialized tool designed to integrate CrewAI agents with the Patronus AI evaluation platform. This tool enables automated evaluation and scoring of agent interactions based on predefined criteria by making API calls to the Patronus platform. It is a crucial component for developers looking to continuously assess and improve the performance of their AI agents through external, criteria-based evaluations.

## Architecture and Component Relationships

The `PatronusPredefinedCriteriaEvalTool` is built upon the `BaseTool` from the [crewai_tool_base](crewai_tool_base.md) module, allowing it to seamlessly integrate into the CrewAI ecosystem as a callable agent tool. It interacts with the external Patronus AI platform for evaluation services and relies on environment variables for secure API key management.

## Core Functionality

The `PatronusPredefinedCriteriaEvalTool` class provides the following key functionality:

### `PatronusPredefinedCriteriaEvalTool`
- **Purpose**: A tool to automatically evaluate and score agent interactions using the Patronus platform. Results are logged to `app.patronus.ai`.
- **Inheritance**: Inherits from `BaseTool`, making it compatible with the CrewAI tool system.
- **Parameters**:
    - `name` (str): Defaults to "Call Patronus API tool for evaluation of model inputs and outputs".
    - `description` (str): Provides a description of the tool's function and arguments. It is dynamically updated if `evaluators` are provided during initialization.
    - `evaluate_url` (str): The endpoint for the Patronus Evaluation API, defaults to "https://api.patronus.ai/v1/evaluate".
    - `args_schema` (type[BaseModel]): Defines the schema for the tool's arguments, using `FixedBaseToolSchema`.
    - `evaluators` (list[dict[str, str]]): A list of dictionaries specifying the predefined evaluation criteria to be used by the Patronus API. This list is passed during tool initialization.
- **Initialization (`__init__`)**:
    - Takes a list of `evaluators` and other keyword arguments.
    - If `evaluators` are provided, the tool's description is updated to reflect this.
- **Execution (`_run`)**:
    - This method is called when the tool is executed by an agent.
    - It extracts the following arguments from `kwargs`:
        - `evaluated_model_input`: The input provided to the evaluated model.
        - `evaluated_model_output`: The output generated by the evaluated model.
        - `evaluated_model_retrieved_context`: Any context retrieved by the model.
        - `evaluated_model_gold_answer`: The expected "gold standard" answer for comparison.
    - It retrieves the `PATRONUS_API_KEY` from environment variables.
    - It constructs a JSON payload with the evaluation data and the predefined `evaluators`.
    - It makes a `POST` request to the `evaluate_url` with the necessary headers and data.
    - If the API call is unsuccessful (status code not 200), it raises an exception.
    - It returns the JSON response from the Patronus API, which typically includes the evaluation results.

## Integration with the Overall System

The `patronus_predefined_evaluator_tool` module is an integral part of the `crewai_tools_platform_automation` ecosystem. It extends CrewAI's capabilities by enabling agents to perform external evaluations using the Patronus AI platform. This allows for:
- **Automated Performance Assessment**: Agents can automatically submit their interaction data for evaluation, providing continuous feedback on their performance.
- **Quality Assurance**: By leveraging predefined criteria on the Patronus platform, developers can ensure that agent outputs meet specific quality standards.
- **Improved Agent Development**: The insights gained from Patronus evaluations can be used to iterate and refine agent behaviors and prompts.

This tool acts as a bridge, allowing CrewAI agents to interact with a specialized external AI evaluation service, thereby enhancing the overall intelligence and reliability of the multi-agent system.
