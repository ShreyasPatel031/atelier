# otel_context_management Module Documentation

## Introduction

The `otel_context_management` module provides a context manager for OpenTelemetry (OTel) span management within the `pydantic_evals` system. Its primary purpose is to capture and organize all spans generated during a specific code execution context into a `SpanTree` for later analysis and reporting.

## Architecture and Component Relationships

This module contains the core logic for collecting and structuring OpenTelemetry spans into a hierarchical tree representation. It plays a crucial role in the `pydantic_evals_reporting` module by enabling the detailed observation and analysis of execution flows within evaluation runs.

## Core Functionality

### `context_subtree`

The `context_subtree` function is a Python context manager designed to capture all OpenTelemetry spans created within its scope.

- **`pydantic_evals.pydantic_evals.otel._context_in_memory_span_exporter.context_subtree`**

  ```python
  def context_subtree() -> typing.Iterator[SpanTree | SpanTreeRecordingError]:
      """Context manager that yields a `SpanTree` containing all spans collected during the context.

      The tree will be empty until the context is exited.

      If no TracerProvider has been configured, a `SpanTreeRecordingError` will be yielded instead of the SpanTree.
      """
      tree = SpanTree()
      with _context_subtree_spans() as spans:
          if isinstance(spans, SpanTreeRecordingError):
              yield spans
              return
          yield tree
      tree.add_readable_spans(spans)
  ```

  This context manager operates as follows:
  1. It initializes an empty `SpanTree` object.
  2. It enters an internal context `_context_subtree_spans()` which is responsible for collecting the raw OpenTelemetry spans.
  3. If `_context_subtree_spans()` encounters an error (e.g., no TracerProvider is configured), it yields a `SpanTreeRecordingError`.
  4. Otherwise, it yields the `SpanTree` object. Importantly, the `SpanTree` will be populated with spans *after* the `context_subtree` context is exited.
  5. Upon exiting the context, the collected raw spans are added to the `SpanTree` object, forming a hierarchical representation of the execution flow.

  **Returns**: A `typing.Iterator` that yields either a `SpanTree` (on success) or a `SpanTreeRecordingError` (if span recording is not possible).

## How the Module Fits into the Overall System

The `otel_context_management` module is a vital part of the `pydantic_evals` ecosystem, specifically within the [pydantic_evals_reporting](pydantic_evals_reporting.md) module. It provides the foundational capability to capture and structure tracing data, which is essential for:

- **Detailed Evaluation Analysis**: By collecting spans, the module enables granular insights into the execution paths and performance characteristics of different components during evaluation runs.
- **Reporting and Visualization**: The `SpanTree` generated by this module can be used by reporting tools to visualize the flow of operations, identify bottlenecks, and understand the dependencies between different parts of an evaluation.
- **Debugging and Troubleshooting**: The structured span data aids developers in debugging complex evaluation scenarios by providing a clear timeline and hierarchy of events.

It serves as a low-level utility that underpins the more high-level reporting and analysis functionalities within `pydantic_evals`.
