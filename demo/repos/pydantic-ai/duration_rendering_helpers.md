# Duration Rendering Helpers

The `duration_rendering_helpers` module provides utility functions for formatting and rendering time durations and their differences in a human-readable format. These helpers are crucial for presenting performance metrics and timing information within reports generated by the `pydantic_evals` system.

## Core Functionality

This module focuses on converting raw duration values (in seconds) into formatted strings, making it easier to interpret elapsed times and performance changes.

## Architecture

The `duration_rendering_helpers` module contains functions that format durations and duration differences. It relies on internal helper functions (not explicitly part of the core components provided) for the actual formatting logic, such as `_render_duration` and `_render_relative`. It's a leaf module within the `pydantic_evals_reporting` and `reporting_renderers` hierarchy, indicating its role in the final presentation layer of evaluation results.

## Component Descriptions

### `default_render_duration(seconds: float) -> str`

Formats a given duration in seconds into a human-readable string. The output format adapts based on the magnitude of the duration:

*   If the duration is less than 1 millisecond, it's displayed in microseconds.
*   If it's less than 1 second, it's displayed in milliseconds.
*   Otherwise, it's displayed in seconds.

This function delegates the actual formatting to an internal `_render_duration` helper, ensuring consistent duration representation across the system.

### `default_render_duration_diff(old: float, new: float) -> str | None`

Calculates and formats the difference between two duration values (`old` and `new`), both in seconds. This function provides both the absolute difference and, if significant, the relative difference.

*   If `old` and `new` are identical, it returns `None`.
*   Otherwise, it returns a string showing the absolute difference (e.g., "+12.34s") and, if a relative difference is meaningful (based on `BASE_THRESHOLD`), it appends the relative difference (e.g., " / +5.0%").

This component utilizes both the internal `_render_duration` for absolute difference formatting and `_render_relative` for calculating and formatting the relative change.
