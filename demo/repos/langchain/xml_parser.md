# xml_parser Module Documentation

The `xml_parser` module provides robust functionality for parsing XML output generated by Language Models (LLMs) into structured Python dictionaries. It is a critical component within the `core_output_parsers` module, enabling the system to process and interpret XML-formatted responses effectively.

## Purpose and Core Functionality

The primary purpose of the `xml_parser` module is to offer a flexible and secure way to extract information from XML strings. It addresses the common challenge of parsing LLM outputs, which may sometimes be ill-formed or include additional text, by providing a specialized `XMLOutputParser` class. This class handles various parsing scenarios, including the extraction of XML content enclosed in triple backticks and the management of XML encoding declarations.

A key feature of this module is its support for different XML parsing backends:
- **`defusedxml`**: The default and recommended parser for enhanced security against common XML vulnerabilities (e.g., DTD expansion, entity bombs).
- **`xml`**: The standard Python library's `xml.etree.ElementTree` parser, available for use in environments where security concerns are mitigated or a streamlined approach is preferred.

It also supports streaming parsing, allowing for efficient processing of large or continuously generated XML outputs.

## Architecture and Component Relationships

The `xml_parser` module consists primarily of the `XMLOutputParser` class, which extends the `BaseTransformOutputParser`. This integration ensures consistency with other output parsers in the `core_output_parsers` module and leverages common transformation capabilities.

The module interacts with external libraries like `defusedxml` and Python's standard `xml.etree.ElementTree` for the actual parsing mechanism. It also depends on the `core_messages` module for handling `BaseMessage` types during streaming operations.

## How the Module Fits into the Overall System

The `xml_parser` module is an integral part of the `core_output_parsers` family, which is responsible for transforming raw LLM outputs into structured and usable formats. It plays a crucial role in scenarios where LLMs are expected to generate XML, such as in tool calling, structured data extraction, or agents that communicate using XML-formatted messages.

By providing a specialized XML parser, this module ensures that downstream components of the system can reliably consume and act upon XML responses, contributing to the overall robustness and interoperability of the LLM-powered applications.

## Core Components

### `XMLOutputParser`

- **Location**: `libs/core/langchain_core/output_parsers/xml.py`
- **Description**: This class is responsible for parsing XML strings into Python dictionaries. It inherits from `BaseTransformOutputParser` and provides methods for both single-shot and streaming XML parsing.

- **Attributes**:
    - `tags`: An optional `list[str]` that can be used to inform the LLM about expected tags in the XML output. This can help guide the LLM to produce better-formed XML.
    - `encoding_matcher`: A `re.Pattern` object used to detect and remove XML encoding declarations from the input string before parsing.
    - `parser`: A `Literal["defusedxml", "xml"]` specifying which underlying XML parsing library to use. Defaults to `"defusedxml"` for security reasons.

- **Methods**:
    - `get_format_instructions() -> str`: Returns a string containing instructions for the LLM on how to format its output as XML, optionally including guidance based on the `tags` attribute.
    - `parse(text: str) -> dict[str, str | list[Any]]`: The main parsing method. It attempts to extract XML content, handles encoding, and then uses the configured parser (`defusedxml` or `xml.etree.ElementTree`) to convert the XML string into a Python dictionary. It raises `OutputParserException` on parsing failures and `ImportError` if `defusedxml` is required but not installed.
    - `_transform(input: Iterator[str | BaseMessage]) -> Iterator[AddableDict]`: Implements streaming parsing for synchronous input streams. It uses an internal `_StreamingParser` to process chunks of text or `BaseMessage` objects.
    - `_atransform(input: AsyncIterator[str | BaseMessage]) -> AsyncIterator[AddableDict]`: Similar to `_transform`, but designed for asynchronous input streams.
    - `_root_to_dict(root: ET.Element) -> dict[str, str | list[Any]]`: A private helper method that recursively converts an `xml.etree.ElementTree.Element` object into a Python dictionary. It handles both simple text content and nested XML structures.
    - `_type` property: Returns the string `"xml"`, identifying the type of the parser.
