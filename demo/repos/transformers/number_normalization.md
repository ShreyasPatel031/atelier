# Module: `number_normalization`

## Introduction
The `number_normalization` module provides utilities for converting numerical values and number-like quantities within text into their English word representations. This is particularly useful in applications such as Text-to-Speech (TTS) systems where numbers need to be spoken out naturally, rather than as raw digits. This module ensures that quantities, currencies, percentages, and other numerical expressions are rendered intelligibly.

## Core Functionality

The primary component of this module is the `EnglishNumberNormalizer` class, which offers robust functionality for transforming various numerical formats into their spoken English equivalents.

### `EnglishNumberNormalizer` Class
(`src.transformers.models.speecht5.number_normalizer.EnglishNumberNormalizer`)

This class is responsible for the intelligent conversion of numbers. It handles:
*   **Integer Conversion**: Converts whole numbers (e.g., 123 to "one hundred and twenty three").
*   **Decimal Numbers**: Supports conversion of numbers with decimal points (e.g., 1.50 to "one point five zero").
*   **Currency Symbols**: Recognizes and converts common currency symbols (e.g., $100 to "one hundred dollars", €50 to "fifty euros").
*   **Negative Numbers**: Correctly prefixes negative numbers with "minus" (e.g., -5 to "minus five").
*   **Percentages**: Appends "percent" to percentage values (e.g., 25% to "twenty five percent").
*   **Number-like Quantities**: Uses regular expressions to identify and normalize various numerical patterns within a given text string.

#### Key Methods:
*   `__init__()`: Initializes the class with predefined lists for number words (ones, teens, tens, thousands) and a dictionary mapping currency symbols to their names.
*   `spell_number(num)`: A helper method that converts an integer (up to 999) into its English word form. This is used internally by the `convert` method.
*   `convert(number)`: This is the core method for converting a single number string (which might include decimals, currency symbols, or percentage signs) into its full English word representation. It parses the input, extracts prefixes/suffixes, and uses `spell_number` for integer and decimal parts.
*   `__call__(text)`: This method allows an instance of `EnglishNumberNormalizer` to be called directly with a string of text. It uses regular expressions (`re` module) to find all numerical patterns in the input text, then applies the `convert` method to each found number, replacing it with its normalized word form. It also handles the cleanup of extraneous spaces.

## Architecture and Component Relationships

The `number_normalization` module is a leaf module primarily serving the [speecht5_models](speecht5_models.md) module, specifically for handling numerical expressions within text that needs to be processed or generated by SpeechT5 models.
