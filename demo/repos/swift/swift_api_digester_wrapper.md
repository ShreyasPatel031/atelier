# swift_api_digester_wrapper

The `swift_api_digester_wrapper` module provides a convenient Python wrapper around the `swift-api-digester` command-line tool. It simplifies the process of generating API baselines and diagnosing API changes across different Swift SDKs and platforms.

## Purpose and Core Functionality

This module's primary purpose is to abstract the complexities of directly invoking `swift-api-digester` by providing a user-friendly command-line interface. It supports two main actions:

1.  **Dump API Baseline (`action=dump`)**:
    *   Generates a JSON representation of a Swift module's API or ABI for a specified target platform (e.g., `iphoneos`, `macosx`).
    *   Allows for filtering modules (e.g., `swift-frameworks-only`, `swift-overlay-only`).
    *   Supports dumping content for an entire SDK, optionally separating output by module or into a zippered directory structure per target.
    *   Utilizes the [sdk_import_inference](sdk_import_inference.md) module to prepare comprehensive module lists.

2.  **Diagnose API Changes (`action=diagnose`)**:
    *   Compares two API or ABI baselines (JSON files generated by the 'dump' action) to identify and report changes.
    *   Helps in tracking API evolution and detecting breaking changes.

## Architecture and Component Relationships

The `swift_api_digester_wrapper` module is structured around its main entry point and two core classes that encapsulate the logic for dumping and diagnosing.

**Key Components:**

*   **`main()` function**: This is the entry point for the module. It parses command-line arguments using `argparse` and dispatches the execution to either `DumpConfig` or `DiagnoseConfig` based on the `--action` argument.
*   **`DumpConfig` class**: Encapsulates the logic for interacting with `swift-api-digester` to perform API dumping. It handles SDK path resolution, target configuration, module filtering, and output formatting (e.g., zippered dumps). It leverages helper functions like `get_sdk_path` and `prepare_module_list`.
*   **`DiagnoseConfig` class**: Manages the comparison of two API baseline files using `swift-api-digester`'s diagnose functionality. It sets up the necessary command-line arguments for the comparison.
*   **Helper Functions**: A set of utility functions like `fatal_error`, `get_api_digester_path`, `check_call`, `check_output`, `prepare_module_list`, and `write_fixed_module` assist in error handling, tool path discovery, external process execution, and module list generation.

## How the Module Fits into the Overall System

The `swift_api_digester_wrapper` module is a crucial part of the `api_checker_utilities` family, which aims to ensure API consistency and prevent unintended breaking changes within the Swift ecosystem.

*   **API Consistency Checks**: By providing a robust way to dump and diagnose API/ABI information, this module enables automated checks in CI/CD pipelines to detect API regressions or unexpected changes.
*   **Integration with `sdk_import_inference`**: Its dependency on the [sdk_import_inference](sdk_import_inference.md) module highlights its role in a broader system for understanding and analyzing Swift SDK modules. `sdk_import_inference` helps in dynamically generating lists of modules to be processed by `swift-api-digester`, ensuring comprehensive coverage.
*   **Toolchain Integration**: The module integrates with the Xcode toolchain by using `xcrun` to locate `swift-api-digester` and SDK paths, making it adaptable to different development environments.
