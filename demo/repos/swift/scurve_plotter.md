# scurve_plotter Module Documentation

The `scurve_plotter` module, a sub-module of `dev_scripts`, provides functionality for generating S-curve plots from CSV data. It is primarily used to visualize performance deltas or similar metrics, presenting them as a distribution over a defined range.

## Purpose and Core Functionality

The primary purpose of `scurve_plotter` is to take structured numerical data, typically generated from benchmark comparisons, and transform it into an S-curve visualization. This helps in understanding the distribution of changes (e.g., performance improvements or regressions) across a dataset.

Its core functionality revolves around the `main` function within `utils.dev-scripts.scurve_printer.main`. This function performs the following key tasks:
1.  **Argument Parsing**: Defines and parses command-line arguments for input/output files, plot titles, and axis customizations (e.g., Y-axis limits and tick marks).
2.  **Data Loading and Validation**: Reads numerical data from a specified CSV file. It expects two columns: one for the X-axis (e.g., cumulative percentage) and one for the Y-axis (e.g., performance delta). It asserts that all data points are non-negative.
3.  **Data Transformation**: Recenters the Y-axis data around 0 (by subtracting 1) to represent percentage differences (e.g., `(new - old) / old`). It then calculates suitable Y-axis limits based on the maximum absolute delta, rounding them to multiples of 5%.
4.  **Plot Generation**: Uses `matplotlib` to create an S-curve plot. It sets appropriate titles, labels, and grid lines, and customizes X and Y-axis ranges and tick marks based on calculated values or user-provided arguments.
5.  **Output**: Saves the generated plot as an image file to the specified output path.

## Architecture and Component Relationships

The `scurve_plotter` module is a self-contained utility focusing on the visualization aspect. It depends on external libraries for numerical processing and plotting, and it typically consumes output generated by related modules within the `dev_scripts` family.

### Component Breakdown:

*   **S-Curve Printer Main (`scurve_printer.main`)**: This is the core entry point of the module. It orchestrates the entire plotting process, from reading arguments and data to generating and saving the plot.
*   **Argparse Library (External)**: Used for robust command-line argument parsing, allowing users to configure the plot's input, output, and visual properties.
*   **NumPy Library (External)**: Utilized for efficient numerical operations on the data arrays, particularly for calculations related to axis limits and data transformations.
*   **Matplotlib Library (External)**: The primary plotting library responsible for creating the S-curve graph, handling all aspects of visualization, including labels, titles, grids, and rendering.
*   **CSV to S-Curve Module (`csv_to_scurve.main`)**: This is a closely related module within `dev_scripts`. It is highly probable that `csv_to_scurve` generates the input CSV files that `scurve_plotter` consumes. This forms a logical data pipeline where `csv_to_scurve` prepares the data, and `scurve_plotter` visualizes it. Refer to the [csv_to_scurve module documentation](csv_to_scurve.md) for more details.

## How the Module Fits into the Overall System

The `scurve_plotter` module is part of the `dev_scripts` collection of utilities. Its role is to provide a standardized way to visualize performance test results or similar data, making it easier for developers and maintainers to identify trends, regressions, or improvements.

It typically works in conjunction with other scripts that generate benchmark data or process raw logs into a CSV format suitable for S-curve plotting. For instance, data might be processed by the [csv_to_scurve module](csv_to_scurve.md) before being fed into `scurve_plotter`.

By providing clear, customizable visualizations, `scurve_plotter` contributes to the overall system's ability to monitor and understand performance characteristics over time.
